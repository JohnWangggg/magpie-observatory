## 全局键

| 键 | 作用 |
| --- | --- |
| `/` | 聚焦日志搜索 |
| `Space` | 暂停 / 恢复实时演示 |
| `T` | 切明暗 |
| `V` | 开视图选择器 |
| `R` | 切回放 |
| `G` | 切自动巡游 |
| `F` | 收藏当前视图 |
| `O` | 影院模式 |
| `⌘K` | 命令面板 |
| `?` | 快捷键表 |
| `Esc` | 关菜单 / 详情条 / 选择器 |

## 视图选择器键

| 键 | 作用 |
| --- | --- |
| `↑↓` | 项间移动 |
| `Tab` / `Shift-Tab` | 组间跳 |
| `Enter` | 切换 |
| `Home` / `End` | 首 / 末项 |
| `Esc` | 关闭 |
| `⌃V` | 切最近 / 全部 |

## 持久化

- 每视图滚动位置（`magpie.scrollPos`）
- 日志查询（`magpie.logQuery`）
- 燃烧选中（`magpie.burnSel`）
- 收藏（`magpie.favorites`）
- 默认视图（`magpie.defaultView`）
- 风格、明暗、密度、动效、巡游间隔、分组方式
- 视图菜单 tab（`magpie.viewMenuTab`）
